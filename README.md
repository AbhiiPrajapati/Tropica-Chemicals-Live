# Tropica sales dashboard

1. Extract this ZIP. Upload index.html and the complete assets folder to your GitHub repository root. Upload .nojekyll too if visible. Do not upload the ZIP itself.
2. In Settings > Pages select Deploy from a branch, main, / (root), then Save.
3. Open the website URL shown on that page after deployment completes.

Keep all three files in assets: trophies.js, three.module.js, tropica-logo.png.

The dashboard includes rotating 3D gold, silver and bronze trophies, glass effects, a motion pause control and the ansoim design credit.

DATA: Current figures are a supplied screenshot snapshot. Live SharePoint synchronization is not connected. Publishing on GitHub does not enable it. Public hosting makes all included sales figures and source code public. Never add Microsoft credentials or tokens to these files.
